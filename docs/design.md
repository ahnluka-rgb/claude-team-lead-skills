# claude-team-lead-skills 설계 (2026-11-02)

## 목적
- AI 결재함 채널로 사람을 데려오는 무료 선물. 영상 설명란 「오늘 쓴 스킬 무료로 받기」.
- 성공 기준: ① 깨끗한 PC에서 설치 한 줄로 바로 돌아간다 ② 결과를 숫자로 증명한다(채널 정직 콘셉트) ③ 회사·개인 흔적 0.

## 결정 (팀장님이 맡기심 → Claude 판단)
- 방향 **C**: 핵심 3개를 깊게 + 플러그인 형식 한 줄 설치.
- 영상 분석은 공개하지 않음(유튜브 약관 위험·내부 무기·시청자와 안 맞음).
- 새 스킬은 **회의록 정리**:
  - 관리자가 매주 하는 일이라 수요가 가장 넓다.
  - 노션·회사 시스템 없이 글만 있으면 된다.
  - 결정·할 일 개수로 채점할 수 있다.
  - 메일 답장은 회사마다 말투가 달라 덜 보편적이다.
  - 일 나누기는 노션 템플릿 영상과 묶어 나중에 낸다.

## 구성
```
.claude-plugin/marketplace.json + plugin.json   ← 저장소 전체가 플러그인 1개(team-lead)
skills/
  weekly-report/   SKILL.md + scripts/merge.py·check.py + sample/make_sample.py(가짜 팀원 엑셀 5개)
  meeting-notes/   SKILL.md + scripts/verify.py(근거 줄 검사) + sample/(가짜 회의 33줄 + 정답·함정 2개)
  daily-log/       SKILL.md + schema.json (처음 실행 때 노션 표 2개를 직접 만들어 줌) + 칸 점검
  token-saver/ ux-writing/ backup/   (점검표형, 덤)
tests/run_checks.py   ← 스크립트·정답 대조 (깃허브에서 윈도우·맥·리눅스 자동 실행)
tests/live/run_live.sh ← 빈 폴더 + 플러그인으로 실제 Claude 실행 3번씩
README.md (한·영, 숫자 결과 표, 시연 GIF) · START_HERE.md · LICENSE
```

## 스킬별 핵심
- **weekly-report**
  - 계산은 Claude가 아니라 `merge.py`(openpyxl)가 해서 숫자가 틀리지 않는다.
  - Claude는 파일 찾기·항목 맞추기·요약 문장을 맡는다.
  - 끝에 원본 합계와 보고서 합계를 대조하는 검사를 꼭 돌린다.
  - 원본은 건드리지 않고 새 파일로만 저장한다.
  - 연습 자료는 기초반 1편 다온상사 자료를 다시 만들어 넣는다.
- **meeting-notes**
  - 녹취·메모 → 결정 사항 / 할 일(담당·마감) / 미정 사항 / 다음 회의 안건.
  - 근거 문장을 줄 번호로 단다(지어내기 방지).
  - 담당이나 마감이 없으면 "미정"으로 쓰고 지어내지 않는다.
- **daily-log**
  - 노션 템플릿(업무 표·일지 표)을 복제하면 설정이 끝나게 한다.
  - 처음 실행 때 표 칸이 맞는지 검사하고, 틀리면 무엇을 고칠지 알려 준다.

## 검증 (공개 전 필수)
1. `tests/run_checks.py`: 연습 자료로 merge.py 실행 → 정답 대조 0건 틀림.
2. 새 빈 폴더 + 플러그인 설치 → `claude -p` 로 세 스킬을 각 3번 실행. 걸린 시간과 틀린 수를 README 표에 기록.
3. 한글 윈도우에서 경로·한글 파일 이름을 확인한다. 맥은 확인 못 하면 "윈도우에서 시험"이라고 밝힌다.
4. 흔적 검사(회사·이름·경로·계정) 0건 → 팀장님 확인 → 공개.

## 하지 않는 것
- 질문 응대, 유료 기능, 회사 실자료 사용, 영상 분석 공개.

## 영상
「별 0개에서 시작합니다」 1화 = 이 저장소를 만드는 과정 + 주간보고 실측 숫자. 쇼츠 끝 2초에 꾸러미 표지.
