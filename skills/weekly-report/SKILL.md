# 주간보고 한 장으로

숫자·줄 세기는 **Claude 가 직접 하지 않고 `scripts/merge.py` 가 한다**(틀리지 않게). Claude 는 폴더 찾기, 모르는 칸 알려 주기, 요약 문장, 검사 결과 보고를 맡는다.
**원본 파일은 절대 고치지 않는다.** 결과는 새 파일로만 저장한다.

## 준비물
- Python 3.9+ 와 `openpyxl` (`pip install openpyxl`). 없으면 설치 명령을 사용자에게 보여 주고 허락받은 뒤 설치한다.

## 순서
1. **폴더 확인**: 사용자가 말한 폴더를 **지금 작업 폴더에서 바로** 찾는다(드라이브 전체를 뒤지는 검색은 하지 않는다 — 오래 걸림). 없으면 사용자에게 경로를 묻는다. `.xlsx` 가 몇 개인지 보여 주고, `~$` 로 시작하는 임시 파일은 뺀다.
2. **합치기**:
   ```bash
   python "<이 스킬 폴더>/scripts/merge.py" "<엑셀 폴더>"
   ```
   - 결과: `<엑셀 폴더>_통합.xlsx` (요약 시트 + 팀원별 시트) 와 같은 이름 `.json`.
   - 화면에 나온 JSON 의 `problems` 를 꼭 본다. `note`(예: 시트가 여러 개라 첫 시트만 읽음)가 있으면 사용자에게 한 줄로 알린다.
3. **모르는 칸 처리**: `problems` 에 「업무 칸을 찾지 못함」이나 `unmapped`(못 읽은 칸 이름)가 있으면, 그 파일의 머리줄을 사용자에게 보여 주고 어느 칸이 업무·상태·마감·메모인지 확인한 뒤 다시 실행한다.
   ```bash
   python merge.py "<폴더>" --map "진척도 체크=task,결과=status"
   ```
   칸 종류: `task`(업무) · `status`(상태) · `due`(마감) · `note`(메모) · `category`(구분).
4. **검사 (빼먹지 말 것)**:
   ```bash
   python "<이 스킬 폴더>/scripts/check.py" "<엑셀 폴더>_통합.xlsx"
   ```
   `"ok": true` 가 아니면 보고서를 넘기지 말고 `problems` 를 고친 뒤 2번부터 다시.
5. **보고**: 아래 틀로 짧게.
   - 한 줄: "팀원 N명 · 업무 N건 (완료 N · 진행 N · 예정 N · 지연·막힘 N) — 원본 N줄과 대조 0건 틀림"
   - **먼저 볼 것**: 지연·막힘 목록(팀원 · 업무 · 이유)
   - 확인 필요(상태를 못 읽은 줄), 중복으로 뺀 줄
   - 결과 파일 경로
   - 팀장에게 올릴 요약 문장 3줄 (숫자는 JSON 그대로, 지어내지 않기)

## 상태를 이렇게 읽는다
| 원래 적은 말 | 정리 |
|---|---|
| 완료, 끝, O, ○, 100% | 완료 |
| 진행, 진행중, 1~99% | 진행 |
| 시작 전, 예정, 0% | 예정 |
| 지연, 늦어짐, 보류, 막힘, X | 지연·막힘 |
| 빈칸·그 밖 | 확인 필요 (사용자에게 물어볼 것) |

## 연습해 보기
`sample/make_sample.py` 를 실행하면 가짜 회사 팀원 5명의 엑셀(양식이 전부 다름)이 생긴다. 정답: 5명 · 15건 · 중복 1줄 · 지연·막힘 3건.
`sample/make_hard_sample.py` 는 더 까다로운 양식(빈 첫 줄·합친 머리칸·✅⏳❌·영어 칸·시트 2개·퍼센트 칸) 3개를 만든다. 정답: 3명 · 9건 · 지연·막힘 2건.
