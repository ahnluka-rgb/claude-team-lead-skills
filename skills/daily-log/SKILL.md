# 업무일지

업무 표는 **읽기만** 하고(고치지 않는다), 일지 페이지를 새로 만든다. 쉬운 말, 사실과 숫자 위주.

## 준비물
- Claude 의 **Notion 커넥터** 연결(Claude 설정 → 커넥터 → Notion → 연결, 쓸 페이지 허용).

## 처음 한 번: 세팅 (사용자가 "세팅해줘" 하거나 설정이 비어 있을 때)
1. 사용자에게 **일지를 둘 노션 페이지** 하나를 묻는다(없으면 새 페이지 「업무일지」를 만들자고 제안).
2. 그 페이지 아래에 데이터베이스 2개를 만든다. 칸 이름·종류는 `schema.json` 그대로.
   - **업무** — 이름(제목) · 담당자(사람 또는 글) · 날짜(날짜) · 상태(선택: 예정/진행/완료/지연) · 프로젝트(글) · 메모(글)
   - **업무일지** — 제목(제목) · 구분(선택: 일간/주간/월간) · 기간(날짜, 시작~끝) · 상태(선택: 초안/확정)
3. 이미 쓰는 업무 표가 있으면 새로 만들지 말고 그 표를 쓴다. 이때 칸을 `schema.json` 과 하나씩 짝지어 보여 주고, 다른 이름이면 짝을 확인받는다.
4. 정한 값(내 이름, 두 표 주소, 칸 짝)을 프로젝트 `CLAUDE.md` 의 `## 업무일지 설정` 에 적는다. 다음부터는 거기서 읽는다.
5. 연습용 업무 3줄을 넣어 아침판을 한 번 만들어 보고, 확인되면 연습 줄은 지운다(지우기 전에 사용자에게 묻기).

## 매번 시작할 때 점검
- `## 업무일지 설정` 이 없으면 → 세팅부터.
- 업무 표를 열어 칸이 그대로인지 본다. 칸이 없어졌거나 이름이 바뀌었으면 무엇이 달라졌는지 말하고 멈춘다(짐작으로 다른 칸을 쓰지 않는다).
- 지금 날짜와 시각을 확인한다. 쉬는 날(주말·설정에 적은 공휴일)이면 아무것도 하지 않는다.

## 언제 무엇을
| 호출 | 만드는 것 |
|---|---|
| 평일, 17시 전 | 「업무일지 M/D(요일)」 아침판 = 오늘 계획 |
| 평일, 17시 뒤 | 같은 페이지를 저녁판 = 결과 보고로 고쳐 씀 |
| 금요일 저녁 | 그날 일간 + 「주간 업무일지 M/D~M/D」 |
| 그 달 마지막 근무일 | + 「월간 업무일지 YYYY년 M월」 |

## 아침판 (기간 = 오늘)
- 맨 위 한 줄: 오늘 할 일 N건 · 밀린 일 N건 · 진행 중 N건
- `## 오늘 할 일` — 날짜가 오늘이고 완료가 아닌 내 업무 (프로젝트·메모 한 줄)
- `## 밀린 일` — 오늘 이전 날짜인데 완료가 아닌 것 (오늘 먼저 할 것)
- `## 진행 중` — 상태 「진행」
- `## 다가오는 일` — 다음 근무일 업무
- 오늘 할 일이 0건이면 그렇다고 쓰고, 손댈 만한 것 1~3개를 「제안」이라고 표시해 적는다.
- `## 메모` — 빈 칸

## 저녁판 (같은 날 아침판을 고쳐 씀)
- 맨 위 한 줄: 오늘 완료 N건 · 진행 중 N건 · 내일 할 일 N건
- 아침 계획 각 항목 옆에 결과: ✅ 완료 / ⏳ 진행 중 / ❌ 못 함 → 다음 날짜
- `## 계획 밖에 한 일` — 계획에 없던 완료 업무
- 완료 업무에는 **메모의 숫자를 그대로** 붙인다(예: 견적 12건 발송). 숫자를 지어내지 않는다.
- `## 내일 할 일` — 다음 근무일 업무
- 사용자가 적은 「메모」는 지우지 않는다. 손님·거래처 사람의 이름·연락처는 빼고 쓴다.

## 주간 · 월간
- 주간(월~금): 그 주 일간 일지를 모아 분야별 주요 완료, 숫자 합계, 못 끝낸 일, 다음 주 할 일, 빈 「메모」.
- 월간: 그 달 주간 일지를 모아 분야별 완료 수, 주요 성과, 끝내지 못한 일, 다음 달 할 일, 빈 「메모」.

## 저장 · 보고
- 업무일지 표에 저장: 구분, 기간, 상태 「초안」. 같은 제목이 있으면 새로 만들지 말고 갱신.
- 끝나면 한 줄: "업무일지 11/2 작성: 완료 9건, 내일 할 일 6건".
